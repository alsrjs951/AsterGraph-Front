# AsterGraph — AG Aperture 로고 가이드

2026-11-01 · 사용자 확정 A안 · 디지털 제품용

A의 실루엣과 G의 열린 입구를 하나의 흐름으로 합친 마크입니다. 앱 UI에서는 블루 심볼과 Ink 워드마크를 사용합니다. 업무 KPI와 근거 그래프 안에는 로고를 반복하지 않습니다.

## 파일 선택

- `public/brand/horizontal-light.svg`, `horizontal-dark.svg`: 가로 조합.
- `stacked-light.svg`, `stacked-dark.svg`: 세로 조합.
- `wordmark-*`: 글자만. `symbol-*`: 심볼만.
- `*-black.svg`, `*-white.svg`: 단색용. White는 내부 공간을 광학 보정했습니다.
- `symbol-small.svg`: 16–24px용, 입구를 24→32 단위로 확장한 별도 도형.
- `public/astergraph.svg`, `astergraph-light.svg`: 앱 테마에 맞춰 자동 전환하는 파비콘.
- `exports/`: PNG, ICO, 앱 아이콘, Apple touch icon, 웹 아이콘. `presentation.html` / `slides/`: 브랜드 목업이며 실제 제품 화면과 구분합니다.

## 크기와 여백

마크 기준은 256×256이며 외곽 폭은 약 195단위입니다. 심볼 바깥에 최소 24단위(256 기준 9.4%)의 여백을 확보합니다. 가로 조합 전체에는 워드마크 높이의 1/4 이상을 확보합니다. 화면에서 가로 조합은 150px 이상, 심볼은 16px 이상을 권장합니다. 24px 이하는 small 마크를 사용합니다.

앱 사이드바는 32px 심볼과 112–126px 워드마크, 좁은 데스크톱은 28px 심볼, 모바일은 심볼만 표시합니다. 엔딩은 96px 심볼과 280–360px 워드마크입니다. 워드마크 비율과 자간은 고정하며 늘이거나 다시 타이핑하지 않습니다. 각 컴포넌트의 내부 SVG는 장식으로 숨기고 부모에 접근성 이름 AsterGraph를 제공합니다.

승인 조합: Light 로고/흰색·라이트 바탕, Dark 로고/네이비 바탕, Black/흰색, White/네이비. 밝은 블루를 흰 바탕에 사용하지 않습니다. 인쇄용 CMYK·Pantone은 아직 지정하지 않았으며 인쇄소 색상 교정 후 확정해야 합니다. 화면용 SVG/PNG를 인쇄 색상 기준으로 간주하지 않습니다.

## 워드마크와 재생성

Manrope OFL 배포판의 560 굵기를 기반으로 As/st/te/er/rG/Gr/ra/ap/ph 간격을 조정했습니다. 모든 글자는 경로로 변환했으며 글꼴 설치나 네트워크 요청이 필요 없습니다. 폰트 라이선스는 `FONT-LICENSE.txt`입니다. 본문 UI는 기존 시스템 글꼴을 유지합니다.

원본 경로 및 앱 상수는 `build_assets.py`로 관리합니다. 재생성에는 오프라인 제작 도구 fontTools가 필요하며 앱 런타임 의존성은 아닙니다. 확정 전 작업 파일은 `../logo-review-round2/`에 보존했습니다.

## 사용 원칙

비율·색상·구성 간격을 유지합니다. 사진 위에서는 충분히 차분한 단색 면을 확보합니다. 그림자·글로우·그라디언트·윤곽선·회전은 추가하지 않습니다. 작은 화면에서 공간이 부족하면 워드마크를 압축하지 말고 심볼만 사용합니다.

로고 파일 및 앱 렌더링을 검수했습니다. 상표 등록 가능성 검토와 실제 인쇄 교정은 이 디지털 적용 작업에 포함되지 않습니다.
